# 채팅 스위치보드 0.1.1 — 테스트 버전

현재 프리셋의 프롬프트와 연결된 월드인포 항목 중 원하는 것만 골라,
해당 채팅에서만 켜고 끄는 SillyTavern 확장 프로그램입니다.
Tavern Helper / JS-Slash-Runner는 필요하지 않습니다.

## 설치

1. SillyTavern의 **확장 프로그램 → 확장 설치**를 엽니다.
2. 아래 저장소 주소를 붙여넣고 설치합니다.

   https://github.com/kkkangkkang-creator/ST-chat-switchboard

3. 브라우저를 새로고침합니다.
4. 채팅을 연 뒤 오른쪽 아래 **◉** 버튼을 누릅니다.
   확장 설정의 **채팅 스위치보드 열기** 버튼으로도 열 수 있습니다.

업데이트는 확장 관리 화면의 업데이트 기능으로 받을 수 있습니다.
이전에 ZIP 버전을 설치했다면 중복 실행을 피하도록 기존 `chat-switchboard` 확장을
비활성화하고 새로고침한 다음 이 저장소 버전을 사용하세요. 같은 채팅 메타데이터 키를
사용하므로 저장된 버튼 구성은 이어집니다.

수동 설치는 저장소 파일을 `SillyTavern/public/scripts/extensions/third-party/ST-chat-switchboard/`
안에 넣고 재시작하면 됩니다. 해당 폴더 바로 아래에 `manifest.json`이 있어야 합니다.
Tavern Helper의 스크립트 가져오기에는 넣지 않습니다.

## 사용

1. **프리셋** 또는 **월드인포** 탭을 고릅니다.
2. **항목 추가**에서 여러 항목을 체크하고 추가합니다.
   월드인포는 책 제목을 눌러 목록을 펼칠 수 있습니다.
3. ON/OFF 스위치를 누르면 다음 답변 생성부터 적용됩니다.
4. **정리**에서 표시 이름, 구획, 순서를 바꿀 수 있습니다.
5. 항목 이름을 누르면 현재 원본 내용을 미리 볼 수 있습니다.

항목 추가는 원본의 현재 ON/OFF 상태를 가져와 이 채팅의 설정으로 고정합니다.
목록 검색은 제목/책/내용 검색, 내 버튼 검색은 이름/구획/출처 검색입니다.

| 동작 | 결과 |
| --- | --- |
| ON / OFF | 이 채팅의 상태를 지정 |
| 원본 따름 | 버튼은 남기고 채팅별 상태 지정 해제 |
| 제거 | 버튼과 채팅별 상태 지정을 함께 제거 |
| 새 채팅 | 별도 설정이 없으므로 원본 상태로 시작 |
| 다른 기존 채팅으로 이동 | 그 채팅에 저장한 구성과 상태 사용 |
| 프리셋 변경 | 이전 프리셋 버튼은 보관하되 적용하지 않음 |
| 월드인포 연결 해제 | 버튼은 보관하되 사용할 수 없음으로 표시 |

## 적용 범위

- 프리셋 기능은 Chat Completion의 프롬프트 목록을 대상으로 합니다.
  Text Completion의 템플릿 관리 기능은 포함하지 않습니다.
- 월드인포는 SillyTavern이 현재 불러오는 전역/캐릭터/채팅/페르소나 연결을 따릅니다.
  첫 버전은 **책 안의 개별 항목**을 제어합니다. 책 자체의 연결/해제는 원래 UI에서 합니다.
- 월드인포 ON은 키워드, 확률, 예산, 캐릭터 제한 등 원래 발동 조건을 유지합니다.
  ON 표시가 이번 답변에 실제 삽입됐다는 뜻은 아닙니다.
- 답변 생성 도중에는 상태 변경을 막습니다. 변경은 생성 완료 후 가능합니다.
- 기존 프롬프트 목록과 월드인포 편집기의 스위치는 **원본 상태**를 표시합니다.
  이 확장의 패널은 **해당 채팅에서 적용할 상태**를 표시하므로 서로 다를 수 있습니다.
- 채팅을 분기하거나 복제해 메타데이터까지 복사하면 설정도 함께 복사될 수 있습니다.
  복사 이후의 설정은 각 채팅에 별도로 저장됩니다.
- 동명의 프롬프트는 ID로 구분하고, 월드인포 ID는 책 이름과 함께 구분합니다.
  프리셋/책 이름 변경 또는 제작자가 항목 ID를 다시 만든 경우에는 다시 추가해야 합니다.

## 저장과 구현

버튼 구성과 상태는 채팅 메타데이터의 `chat_switchboard_v1`에 저장합니다.
원본 프리셋/월드인포 파일, API 설정, 캐릭터 카드에는 쓰지 않습니다.
프리셋 전체 내용과 월드인포 본문도 채팅 설정에 복제하지 않습니다.

프리셋은 PromptManager의 읽기 메서드에 채팅별 활성 상태가 반영된 뷰를 제공하며,
원본 순서 배열과 enabled 값은 변경하지 않습니다. 월드인포는
`WORLDINFO_ENTRIES_LOADED`에서 캐시 원본이 아닌 항목 사본에 disable 값을 반영합니다.
외부 API나 CDN에 요청하지 않으며, 빌드/패키지 설치 없이 동작하도록 작성했습니다.

## 확인한 범위와 한계

2026-09-07 확인한 SillyTavern **1.18.0 release 소스 구조**를 기준으로 작성했습니다.
해당 버전의 실제 PromptManager 읽기 메서드를 가져와 다음 로직 테스트를 통과했습니다.

- 채팅 A/B의 ON/OFF 분리 및 원본 데이터 불변
- 프리셋 변경 시 이전 프리셋 설정 미적용
- 기본 시스템 프롬프트 OFF와 생성 종류별 트리거 조건 유지
- 원본 따름으로 초기화 및 중복 제목을 가진 항목의 ID 구분
- 여러 경로로 연결된 같은 월드인포 항목의 OFF 적용
- 다른 책의 동일 ID 분리, 키워드·확률 조건 보존
- JavaScript 구문 검사

0.1.1에서는 확장의 실제 시작 파일을 Node의 모듈 실행 환경에 불러와,
메모리 내 DOM/이벤트 모형과 연결하는 추가 테스트도 통과했습니다.

- 항목 선택창의 추가/닫기 처리, 프리셋·월드인포 스위치 콜백
- 저장 대상 채팅 확인, A/B 전환 및 이전 설정 복원
- 생성 중 버튼 잠금, 원본 따름 및 항목 제거
- 비활성화 시 이벤트/화면/프롬프트 래퍼 정리 및 재활성화
- 재활성화 시 중복 등록 방지, 생성 중 비활성화 시 생성 중단

창 닫기 이벤트 순서에 영향을 받지 않도록 보완했고, 확장을 끈 뒤 예약된 갱신이
다시 활성화하지 않도록 보호했습니다. 이 검증은 브라우저 화면 렌더링 검증과는 다릅니다.

**실제 SillyTavern 서버에서 답변을 생성하는 통합 테스트, 화면 조작, 모바일 화면의
시각 검증은 아직 완료하지 못했습니다.** 테스트 브라우저의 로컬 주소 접근이
승인되지 않아 브라우저 테스트는 실행하지 못했습니다. 사용자의 설치 버전과
다른 확장 프로그램 조합에서 추가 확인이 필요한 첫 테스트 버전입니다.

문제가 있으면 SillyTavern 버전, 어떤 탭/버튼에서 발생했는지, 화면 또는 오류 문구를 알려주세요.

## 비활성화 / 제거

확장 관리에서 비활성화하고 새로고침하면 채팅별 덮어쓰기가 더 이상 적용되지 않습니다.
수동으로 제거할 때는 설치한 `ST-chat-switchboard` 폴더를 제거한 뒤 새로고침하세요.
채팅에 저장된 작은 설정은 남아 있으므로 다시 설치하면 복원할 수 있습니다.
